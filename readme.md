# Task 11: CSS Mini Project - Thala 7 Sneaker Store

1. Landing Page:
   - Header with Logo left, Menus center, icons right using Flexbox
   - Hero Section with 2 divs (text + image), Shop Now button with transform hover
   - Service Overview Section full width orange bar with Reviews, Customers, Rating, Quality
   - Hamburger menu visible only in mobile using :focus-within pseudo class

2. Product Display Page:
   - Header same as landing
   - Main display: left main image, right product name, description, price, sale, quantity, add to cart
   - Bottom gallery with flex and horizontal scroll

3. Shopping Cart Section:
   - Left: Shopping Cart heading, table Product/Quantity/Price with remove icon
   - Right: Coupon input, Apply Coupon, Sub Total, Taxes, Discount, Total, Pay Now, Razorpay icons
   - Continue Shopping link at bottom

4. Payment Section:
   - Left: Checkout heading, Email ID input, Payment card with Card/Crypto/Bank options, Card Number, Expiry, CVC, Country, ZIP
   - Right: Order Summary, Coupon, Sub Total, Taxes, Discount, Total, Pay Now button, Razorpay icons

- No Bootstrap, only CSS
- Fully responsive
